# 設計仕様

ファミリー名Suginami Sans、静的Extended Bold。横に広い字形、広い内側の空間、太い縦線、水平な端部を持ちます。aは二階建て、gは一階建て。通常yと、上を開いたgに近い代替yを共存させます。代替yの右縦線は直線で、下端は左へ回り、上端はzと揃います。

輪郭はsource/glyphs.jsonと追加記号JSON、現在の編集原本はUFOです。カーニングとベアリングはspacing-plan.json、小サイズ補正はsmall-size-plan.jsonとrelease-size-plan.jsonに保存します。座標系と再生成手順はBUILD.mdを参照してください。

標準幅・Regular・バリアブル版は未設計です。将来幅軸へ進む場合は単純な横縮小ではなく縦線の太さと内側の空間を設計し、補間前に輪郭・点数・順序・開始点の対応を確認します。現行版に変形軸はありません。
