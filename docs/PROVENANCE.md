# 制作経緯と確認範囲

既存書体名・フォントファイル・他社の図形等を指定せずに画像生成した案を起点とし、受領したSVG/JSONのベジェ輪郭から独自書体として制作しています。これは2026-10-25に本人から確認した説明で、生成時の入力や会話ログを独立に照合したものではありません。

この実装はJSONと編集用UFOの輪郭を使います。第三者フォントの輪郭を取り込む処理はありません。追加記号は既存のSや新しい直線パスから構成し、光学補正は既存曲線への明示的な座標調整として保存しています。

これは制作経緯と実装の確認記録です。既存書体との網羅的な照合や、第三者の権利の非侵害を保証するものではありません。2026-11-08に本人がSIL Open Font License 1.1による配布を承認しました。権利者表記はKouki Ojima、予約フォント名は指定していません。正本はルートのOFL.txt、適用範囲はLICENSING.mdを参照してください。
