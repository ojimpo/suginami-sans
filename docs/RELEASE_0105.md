# Suginami Sans Extended Bold 0.105

独立した書体リポジトリの静的Releaseです。OTFとTTFは従来の0.105とバイト同一で、今回の整備は見本と配布物が対象です。

## 配布内容

- `SuginamiSans-ExtendedBold.otf` / `.ttf`：静的Extended Bold。通常はどちらか一方を利用。
- `SuginamiSans-ExtendedBold-0.105.zip`：フォント、使い方、制作経緯、検証記録、画像・HTMLの見本。
- `specimen.png`：見出しと187語・3段落の文章、字形一覧、通常y／代替y、字間とサイズの比較。
- `SHA256SUMS.txt`：上記4ファイルのSHA-256。

HTML見本は本文サイズと行間を切り替え、文章の改行・密度を比較できます。自由入力、OTF／TTF、ss01、カーニング、反転、未収録警告とリセットも備えています。スマートフォン表示にも対応しています。

## フォント

印字可能ASCII95文字とen/em dash、未符号化のy.altを収録し、全99グリフ・97 Unicodeです。代替yはスタイルセット1（ss01）で切り替えます。a/sの開口部と%/@の線・通路は0.105の小サイズ補正を維持しています。

UFOからのビルド、初期JSONからの再生成、静的検証、FreeTypeの970件＋640件、実ブラウザでのフォント機能・操作・レイアウト、配布ZIPの読み戻しを確認しています。詳細はVALIDATION.mdを参照してください。

日本語・アクセント付き文字は未収録です。I/lは同形、ヒンティングは未実装で、インストール後のWord/Adobe等は未検証です。標準幅・Regular・バリアブル版は未設計です。

このReleaseはprivateリポジトリ内の配布です。一般向けの配布ライセンスは未設定です。
