# Suginami Sans Extended Bold 0.106

SIL Open Font License 1.1を適用した一般公開版です。フォントのcopyright・ライセンス全文・参照URLをOTF/TTFへ埋め込み、UFO・ソース・文書・配布ZIPを整備しました。予約フォント名は指定していません。

輪郭、字幅、Unicode、ss01、カーニング、行メトリクスは0.105から変更していません。フォント内の版とライセンス情報が変わるため、バイナリとチェックサムは更新されています。

## ダウンロード

- `SuginamiSans-ExtendedBold-0.106.zip`：フォント・使い方・OFL・制作経緯・検証記録・画像とHTMLの見本。
- `SuginamiSans-ExtendedBold.otf` / `.ttf`：フォント単体。利用する形式を一方選んでください。
- `OFL.txt`：著作権表示とライセンス全文。フォント単体を再配布する場合も一緒に保持してください。
- `specimen.png`：見出し・187語の3段落・全体の字形・y・カーニング・サイズの画像見本。
- `SHA256SUMS.txt`：上記5ファイルのSHA-256。

商用利用、Webへの組み込み、改変、再配布ができます。フォントの再配布には著作権表示とOFLを維持し、改変版もOFLで配布してください。フォント単体の販売はできません。作成したロゴや文書等にOFLを適用する必要はありません。詳細はOFL.txtをご確認ください。

全99グリフ・97 Unicode。印字可能ASCII95文字とen/em dash、未符号化の代替yを収録し、ss01で切り替えます。日本語・アクセント付き文字は未収録です。ヒンティング未実装、I/lは同形で、Word/Adobe等へのインストール後の評価は未完了です。
